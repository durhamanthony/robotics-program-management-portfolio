# Site Readiness Checklist — Warehouse

Owner records evidence and marks each item Ready, Conditional, or Not Ready. Any safety-critical Not Ready item blocks shipment or commissioning.

| Area | Readiness requirement | Evidence / owner |
|---|---|---|
| Process | Approved carton, trailer, pallet, conveyor, reject, and exception envelopes | Process map and sample set / Operations |
| Layout | Robot lanes, stops, egress, exclusion zones, pallet locations, forklift route | Marked layout / Facilities + EHS |
| Floor/dock | Level, dry, load-rated, gap/edge controls, lighting, housekeeping | Survey / Facilities |
| Safety | Risk assessment inputs, guarding/signage, stops, LOTO/recovery process | Safety file / EHS + qualified safety lead |
| Power/charging | Circuits, receptacles, chargers, protection, ventilation, cable routing | Electrical signoff / Facilities |
| Network | Coverage, segmentation, ports, DNS/NTP, certificates, latency/failover | Test report / IT |
| Security | Robot identities, RBAC, remote-access approval, logging, retention | Security approval / Security |
| Integration | WMS/conveyor endpoints, test data, failure modes, rollback | Interface test / Integration lead |
| Operations | Shift owner, operators, interventions, material availability, downtime window | Roster / Site lead |
| Support | Installed base, entitlement, on-call, spares, tools, field access | Support drill / Service lead |
| Logistics | Delivery slot, dock, rigging, storage, asset receipt, damage inspection | Logistics plan / Customer PM |
| Acceptance | Witnesses, scripts, measurement method, signoff authority | Approved test plan / PM |

## Readiness review

The program manager holds the review at W-3 and W-1 before shipment. Conditional items require owner, due date, compensating control, and approver. Evidence is versioned and retained with the acceptance package.
