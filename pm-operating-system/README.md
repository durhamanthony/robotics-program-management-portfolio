# Reusable Robotics Program Management Operating System

> **Evidence-confidence key:** [PB-H] public benchmark or authoritative source/high confidence; [RBE-M] range-based estimate/medium confidence; [SA-L] scenario assumption/low confidence; [DC-L] disclosed derived calculation/confidence inherits the weakest input; [UPV] unverified production value/block commitment until approved.


This kit turns the portfolio's controls into reusable working files. The Word templates support executive decisions and site acceptance; the Excel workbook is the integrated control surface; the CSVs are portable system-of-record seeds; and the AI playbook defines safe, reviewable assistance.

## Start here

1. Copy the template set into a controlled project workspace.
2. Assign an owner and update cadence for every register.
3. Replace all example values and `[ENTER]` fields with approved project data.
4. Keep assumptions separate from observed or signed evidence.
5. Require a human approver for safety, privacy, security, finance, supplier, customer, and release decisions.
6. Export a dated evidence pack at every gate.

## Evidence model

- `PB-H` — public benchmark or authoritative source, high confidence for the stated fact.
- `RBE-M` — range-based estimate, medium confidence pending quotes or measurements.
- `SA-L` — scenario assumption, low confidence until validated.
- `DC-L` — derived calculation using disclosed assumptions; confidence inherits the weakest input.
- `UPV` — unverified production value; do not use for a commitment.

All templates are examples, not signed records. A completed record must identify the evidence location, owner, review date, and approval state.
