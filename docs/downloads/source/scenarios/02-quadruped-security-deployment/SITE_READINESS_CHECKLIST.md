# Site Readiness Checklist — Night Security

> **Evidence-confidence key:** [PB-H] public benchmark or authoritative source/high confidence; [RBE-M] range-based estimate/medium confidence; [SA-L] scenario assumption/low confidence; [DC-L] disclosed derived calculation/confidence inherits the weakest input; [UPV] unverified production value/block commitment until approved.


**Table 1. Site Readiness Checklist — Night Security — Evidence: disclosed row/source notes; Confidence: see evidence key and row/source notes**

| Area | Readiness requirement | Evidence / owner |
|---|---|---|
| Authority | Approved purpose, operating hours, decision rights, responder role | Concept of Operations (CONOPS) / Security lead |
| Privacy/legal | Collection zones, notices, retention, access, disclosure, incident process | Impact review / Privacy/legal |
| Routes | Day/night walk, slope/surface/curb/stair/drop-off, gates, traffic, animals | Hazard map / Site + EHS |
| Geofences | Allowed, restricted, no-record, dock, and recovery zones validated | Route test / Robotics lead |
| Lighting/weather | Operating thresholds and degraded-condition decision rules | Limits matrix / Operations |
| Docks/power | Secure access, charging, fire/electrical review, conflict prevention | Inspection / Facilities |
| Connectivity | Coverage heatmap, roaming, dead-zone behavior, failover | Test report / IT |
| Cybersecurity | Device identity, RBAC/MFA, remote access, audit, update controls | Approval / Security |
| Alert/evidence | Alert taxonomy, routing, timestamp, chain of custody, export | End-to-end drill / SOC lead |
| Retrieval | Location, weight, transport aid, two-person rules, emergency contacts | Drill / Field service |
| Support | Installed base, cases, telemetry, on-call, spares, dispatch | Support drill / Service lead |
| People | Operators/responders/support trained; workforce notified | Roster / Training lead |

Any unresolved geofence, drop-off, public-access, privacy, or safe-return condition blocks unattended route activation.
