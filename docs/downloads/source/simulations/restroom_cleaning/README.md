# Public Restroom Humanoid Cleaning — MuJoCo Capability Demo

This model represents a human-scale robot operating in an existing public restroom. The demonstration covers entry and occupancy verification, sink and mirror cleaning, toilet-area cleaning, targeted floor care, consumable replenishment, trash removal, and a controlled stop when a sharps or biological hazard is detected.

Light-bulb replacement is intentionally excluded. Electrical and work-at-height maintenance requires a separate risk assessment, isolation procedure, and qualified human maintenance process.

The simulation is a fictional generic capability demonstration, not a certified cleaning process or a claim of autonomous production performance.
