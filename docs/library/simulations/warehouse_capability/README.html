Warehouse Palletizing and Truck Loading — MuJoCo Capability Demo

This separate capability scene restores the warehouse workflow without making it one of the four complete project case studies. Two representative humanoid work cells pick cartons from conveyors and build a seven-carton pallet. A robot-operated forklift transfers the pallet into an open-backed green truck and returns for the next cycle.

The demonstration is a fictional generic capability simulation. It does not represent a production deployment or a validated robot controller.
