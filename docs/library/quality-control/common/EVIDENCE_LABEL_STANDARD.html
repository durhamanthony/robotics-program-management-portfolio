Evidence and Confidence Standard

Evidence-confidence key: [PB-H] public benchmark or authoritative source/high confidence; [RBE-M] range-based estimate/medium confidence; [SA-L] scenario assumption/low confidence; [DC-L] disclosed derived calculation/confidence inherits the weakest input; [UPV] unverified production value/block commitment until approved.

Use the pair evidence_class + confidence for every material claim or number.

Table 1. Evidence and Confidence Standard — Evidence: disclosed row/source notes; Confidence: see evidence key and row/source notes

Code Meaning Default confidence Release rule
PB-H Public benchmark or authoritative source High Verify source identity, date, and applicability
RBE-M Range-based estimate Medium Replace with quotes or observations before commitment
SA-L Scenario assumption Low Never present as actual performance or price
DC-L Derived calculation Low Recalculate; confidence cannot exceed weakest input
UPV Unverified production value Unverified Block commitment until approved evidence exists

The reviewer must downgrade confidence where the cited material does not support the precise claim.
