Incident and Escalation Plan — Night Security

Immediate priorities

Protect people and site, stop or secure the robot through approved controls, preserve evidence, notify the human security chain, and avoid speculative public/customer statements.

Event Immediate action Required escalation
Injury, near miss, fire, uncontrolled motion Emergency/site procedure; approved stop; do not restart EHS, security command, executive/legal, vendor incident lead
Geofence/public-area breach Safe stop/return if appropriate; dispatch human; preserve route/config Security, privacy/legal, robotics lead
Suspected cyber compromise Isolate through approved procedure; preserve logs; revoke access if authorized Security incident response, service, legal/privacy
Missing robot/comms loss Last-known position, route safety check, human retrieval protocol SOC supervisor, field service, site security
Material privacy/evidence event Stop affected processing if directed; preserve audit trail Privacy/legal and security incident process
False/late alert trend Human coverage adjustment; create problem record Service owner, security operations, product/engineering

Command and communications

The site incident commander owns immediate site response. The service incident manager coordinates technical restoration and timeline. Legal/privacy/security approve regulated communications. Customer updates state confirmed facts, impact, actions, next update, and owner. Restart requires documented safety/security/privacy disposition and authorized approval.
