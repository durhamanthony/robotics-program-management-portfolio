First Customer Launch Plan

Commercial/operating clarity

Contracted use case and environment; supported payload; expected throughput; customer dependencies; data ownership/retention; software/update terms; safety responsibilities; warranty/support hours; response/restoration; spares/travel; acceptance tests; cure period; change orders; expansion gate; termination/transition.

Readiness checklist

  • First-customer problem and baseline reconfirmed.
  • Production unit serial/configuration/release record complete.
  • Site/facility/network/safety/data controls ready.
  • Factory Acceptance Test (FAT) defects and Design Verification Test (DVT) / Production Validation Test (PVT) deviations dispositioned.
  • Shipping, rigging, tools, installation, calibration, and recovery planned.
  • Customer operator/maintenance/support roles and training scheduled.
  • Level 1 (L1), Level 2 (L2), field, and Level 3 (L3) escalation; on-call; case portal; remote access; telemetry; spares; and Return Material Authorization (RMA) tested.
  • Acceptance, soak, cutover, rollback, communications, and incident command approved.

Launch sequence

Ship -> receipt/inspection -> install -> configuration/calibration -> safety validation -> dry missions -> representative payloads -> exception tests -> operator assessment -> controlled pilot -> acceptance soak -> signoff -> hypercare -> 30-day review -> expansion/General Availability recommendation.

Feedback loop

Every customer observation is classified as training/process, site/configuration, documentation/knowledge, support defect, product defect, requirement gap, or roadmap request. Product owns prioritization; engineering owns technical resolution; program management ensures customer impact, evidence, schedule, and decision closure.
