Product Roadmap — AD-01

Roadmap items are outcome hypotheses subject to gate evidence; dates are scenario targets.

Gate abbreviations are Engineering Verification Test (EVT), Design Verification Test (DVT), Production Validation Test (PVT), and General Availability (GA).

Horizon Outcome Capabilities Exit evidence
0–3 months Validate a valuable repeatable workflow Discovery, mock workflow, payload/layout data, initial hazard analysis Concept gate
4–7 months Prove core architecture Mobility/manipulation prototype, supervised mission, telemetry, safe-state concepts EVT gate
8–12 months Verify product design Integrated hardware/software, supported envelope, security/update, serviceability, reliability growth DVT gate
13–15 months Prove repeatable build/release Pilot line, work instructions, end-of-line test, configuration, service stock PVT gate
16–18 months Achieve first customer acceptance Site integration, training, support, controlled launch, 30-day review First-sale/GA decision

Deferred beyond first release

Outdoor operation, stairs, public access, arbitrary objects, multiple mobile pickup/drop layouts, hazardous payloads, unsupervised site expansion, and advanced fleet optimization. Each requires a new evidence and commercial case rather than silent scope creep.
