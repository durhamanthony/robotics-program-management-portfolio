Workflow demonstrations

Recruiters and hiring managers can play completed operational animations directly in the browser. No command line, Python installation, or MuJoCo setup is required.

CASE 01

Retail backroom fulfillment workflow animation

A browser-playable operational animation shows a tablet request, walking through an unchanged stockroom, stair traversal, shoe-box retrieval, employee handoff, and inventory confirmation. It demonstrates the program workflow; it is not a robot-performance test.

CASE 02

Human-supervised quadruped night-patrol simulation

Two quadrupeds patrol independent routes while a third remains available for charging rotation. The run demonstrates rough terrain, steps, anomaly escalation, human verification, network safe stop, sensor degradation, and low-battery docking.

CASE 03

AD-01 tote-transfer product simulation

A narrow product demonstration of the AD-01 two-station tote-transfer workflow, including transfer, route travel, placement, and a controlled fault state.

Robotics support triage and evidence demonstration
